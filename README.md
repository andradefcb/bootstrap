# AutoNorte Veículos — Trabalho Prático de Programação Web

Site fictício de uma revenda de veículos, feito com **HTML5 + Bootstrap 5.3**, sem nenhum arquivo CSS próprio.
O layout segue o protótipo feito no Figma: https://www.figma.com/design/G24KX4K2Ojn57LhaVsWoSi

## Páginas

| Arquivo | Página | Conteúdo |
|---|---|---|
| `index.html` | Home | Menu, banner, apresentação da empresa, veículos em destaque, chamada e rodapé |
| `veiculos.html` | Veículos / Venda | Filtros e 6 veículos em Grid + Cards (foto, marca, modelo, ano, km, preço, "Ver detalhes") |
| `detalhes.html` | Detalhes do veículo | Galeria, ficha técnica (ano, km, combustível, câmbio, cor), preço, descrição e botão de contato |
| `contato.html` | Contato | Informações da empresa e formulário (nome, e-mail, telefone, assunto, mensagem) |

## Estrutura

```
index.html
veiculos.html
detalhes.html
contato.html
img/        imagens usadas no site
```

## Recursos do Bootstrap utilizados

Navbar (com menu recolhível no celular), Grid System, Cards, Buttons, Forms, Breadcrumb, List group, Badges,
Containers, classes de espaçamento/alinhamento/cores e Bootstrap Icons.

Bootstrap e Bootstrap Icons são carregados por CDN, então é preciso estar com internet ao abrir as páginas.
